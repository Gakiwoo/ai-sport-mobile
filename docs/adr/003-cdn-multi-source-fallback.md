# ADR-003: CDN 多源回退策略

| 属性 | 值 |
|------|-----|
| 状态 | 已采纳 |
| 日期 | 2024-05 |
| 决策者 | Gakiwoo |

## 上下文

MediaPipe 模型文件（wasm/tflite）约 22MB，首次启动需要下载到本地缓存。如果只依赖单一 CDN 源，当该源不可用时，用户无法使用应用。国内网络环境复杂，需要确保模型文件的可靠下载。

## 决策

采用 **多源优先级回退 + 并发控制 + 本地缓存验证** 策略：

1. 定义 CDN 源优先级列表：`gakiwoo.com` → `npmmirror.com` → `jsdelivr` → `unpkg`
2. 依次尝试下载，单个源超时 15 秒后自动切换下一源
3. 使用 `asyncPool` 控制并发下载数（最多 3 个并发）
4. 下载完成后验证文件清单（`mediaPipeManifest`），确保完整性
5. 验证通过后缓存到本地，后续启动直接使用本地文件

## 可选方案

### 方案 A: 单一 CDN 源

- **优点**: 实现简单
- **缺点**: 单点故障，CDN 不可用时用户无法使用
- **结论**: 否决

### 方案 B: 多源并行下载（竞速）

- **优点**: 下载速度最快
- **缺点**: 浪费带宽、CDN 计费翻倍、实现复杂
- **结论**: 否决

### 方案 C: 多源优先级回退（采纳）

- **优点**: 可靠性高、带宽友好、优先使用自有 CDN（可控性高）
- **缺点**: 回退时延迟增加（最多 4 × 15s = 60s 极端情况）
- **结论**: 采纳

## 影响

- 首次启动下载延迟取决于网络和 CDN 可用性
- `mediaPipeCdnPolicy.ts` 中的 `shouldPreloadMediaPipeAssets()` 控制预加载时机
- `mediaPipeManifest.ts` 验证缓存完整性
- 环境变量 `EXPO_PUBLIC_MEDIAPIPE_CDN_BASES` 可自定义 CDN 源列表
